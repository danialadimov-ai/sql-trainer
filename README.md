# 🗄️ SQL Тренажёр

Современный интерактивный тренажёр SQL прямо в браузере. Учебная база — магазин компьютерной техники. Без сервера, без базы данных, без установки — всё работает на клиенте.

## Возможности

- **Практика** — 8 задач трёх уровней сложности (лёгкий / средний / сложный) с редактором запросов, подсказками и эталонными решениями
- **Проверка по результату**, а не по тексту запроса — любой правильный вариант засчитывается
- **✨ ИИ-конструктор заданий** — опишите, что хотите потренировать, и ИИ составит задачу по учебной базе. Каждое задание автоматически проверяется: эталонный запрос должен выполниться и вернуть непустой результат
- **Материалы** — подборка открытых источников для изучения SQL
- **Прогресс** сохраняется в браузере, светлая/тёмная тема, адаптивный дизайн для телефона
- **Плавные анимации** интерфейса

## Быстрый старт

Скачайте репозиторий и выберите любой способ:

**Способ 1 — просто открыть файл**
Откройте `index.html` в любом браузере (двойной клик или `start.bat`). Всё работает офлайн.

**Способ 2 — локальный сервер (Windows)**
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Затем откройте http://localhost:8585

## ИИ-конструктор

Конструктор работает из коробки через бесплатный онлайн-ИИ, а при его недоступности — через локальный генератор по шаблонам. Для максимального качества заданий укажите свой бесплатный ключ в настройках (⚙️ в правом нижнем углу страницы):

- **Google Gemini** — aistudio.google.com/apikey
- **Groq / Llama** — console.groq.com/keys
- Любой OpenAI-совместимый API

Ключ хранится только в вашем браузере (localStorage) и отправляется лишь в API выбранного провайдера.

Чтобы встроить ключ для всех посетителей своей копии сайта, впишите его в `BUILTIN_KEY` в начале скрипта в `index.html`.

## Учебная база

| Таблица | Столбцы |
|---|---|
| `categories` | id, name |
| `products` | id, name, category_id, brand, price, stock |
| `orders` | id, product_id, customer, qty, status, order_date |

Статусы заказов: `paid`, `new`, `cancelled`.

## Технологии

- Один HTML-файл, ванильный JS — без сборки
- [AlaSQL](https://github.com/AlaSQL/alasql) — SQL-движок в браузере (включён локально, работает офлайн)
- Разрешены только запросы `SELECT`; оконные функции и CTE не поддерживаются (ограничение AlaSQL)
